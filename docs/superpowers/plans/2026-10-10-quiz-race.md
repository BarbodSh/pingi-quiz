# Quiz Race Implementation Plan

> Executed natively (inline) per user's "go ahead and build it".

**Goal:** LAN multiplayer timed quiz race, zero dependencies, `node server.js`.
**Architecture:** Pure in-memory `game.js` (RoomManager, injectable `now`/`rng`) + thin `server.js` (http, JSON API, SSE broadcast, 200 ms tick) + single-page `public/index.html` that renders whatever room state the server pushes.
**Tech Stack:** Node 20 built-ins (`http`, `fs`, `os`, `crypto`, `node:test`), vanilla HTML/CSS/JS.
**Spec:** `docs/superpowers/specs/2026-10-10-quiz-race-design.md`

## Global Constraints
- No npm dependencies, no database. Questions in `questions.json`.
- Correct answer never present in public state while phase is `countdown` or `question`.

## Review Focus
1. Player refreshes mid-question → same playerId reconnects, answer/score kept.
2. Host closes tab → host role passes to another connected player after a 5 s grace.
3. Answer sent after deadline / twice / by unknown player → rejected, score unchanged.
4. Everyone answers early → reveal starts immediately (disconnected players don't block).
5. Pool smaller than requested count → race uses whole pool.

## Tasks
### Task 1: `questions.json` — 60 Programming questions (20 easy / 20 medium / 20 hard).
### Task 2: `game.js` + `test/game.test.js` (TDD)
RoomManager(questions, {rng}) with: `categories()`, `createRoom(opts, now)`, `joinRoom(code, name, now)`,
`start(code, pid, now)`, `answer(code, pid, option, now)`, `restart(code, pid, now)`,
`setConnected(code, pid, bool, now)`, `tick(now) → {changed: string[], removed: string[]}`,
`publicState(code, pid, now)`, `hasPlayer(code, pid)`. Errors: `GameError(message, status)`.
Phases: lobby → countdown(3 s) → question(N s) ⇄ reveal(4 s) → final.
### Task 3: `server.js` — routes from spec, SSE per player, broadcast on change, tick loop, LAN URLs.
### Task 4: `public/index.html` — home/lobby/countdown/question/reveal/final screens, clock-offset timer, sessionStorage reconnect.
### Task 5: Verify — `node --test`, then a two-player race in the browser via Playwright.
